# Задача C: анти-спуфинг (настоящий голос или синтез), метрика ROC-AUC

Финал: seed **185065**, публичный LB **99.01**. Обучение только на train задачи, предобученных
анти-спуфинг-моделей нет, тест для обучения и подбора не используется.

## Запуск
```bash
pip install -r requirements.txt
python task_c/features.py --split train            # признаки train -> task_c/features/
python task_c/train.py --seed 185065                # обучение -> task_c/weights/
python task_c/predict.py --test-dir <папка с .wav> --out-dir out   # без обучения -> out/submission_seed_185065.csv
```
`predict.py` сам считает признаки из аудио (около 5–10 минут на CPU).

## Признаки (`features.py`)
- Обрезка тишины по краям (top_db=35): в ASVspoof 2019 длина пауз коррелирует с меткой, и без обрезки
  модель учит этот «шорткат». Длительность в признаки не входит.
- LFCC (20 коэффициентов с Δ и ΔΔ; линейные фильтры лучше видят высокие частоты, где остаются следы вокодеров),
  MFCC 20, энергии 16 частотных полос, центроид/ширина/плоскостность/rolloff. По времени берутся среднее и std:
  итого 200 признаков.

## Модель
Среднее рангов трёх групп: LightGBM ×5 seed (balanced), CatBoost depth 6 ×3 seed и CatBoost depth 8 ×3 seed.

## Валидация
Leave-one-attack-out: обучение на 5 атаках из A01–A06, проверка на оставшейся, bonafide разделены по
говорящим. Так проверяется перенос на незнакомые синтезаторы. Результаты в `results.csv`.

| Вариант | mean AUC (LOAO) | худшая атака | Публичный LB |
|---|---|---|---|
| признаки + логрег | 0.936 | 0.655 (A05) | — |
| признаки + LightGBM | 0.979 | 0.896 | 98.46 |
| WavLM-base-plus, слой 6 + логрег | 0.976 | 0.918 | 45.86 |
| признаки + WavLM (смесь) | — | — | 79.88 |
| LightGBM ×5 / CatBoost / их смесь | — | — | 98.72 / 98.82 / 98.85 |
| LGBM ×5 + CatBoost d6 ×3 + d8 ×3 (финал) | — | — | **99.01** |

Выводы: SSL-признаки (WavLM) на CV не хуже, но на тесте проваливаются (45.86): они не переносятся на
синтезаторы теста. Ручные спектральные признаки устойчивы, ансамбль разных бустингов добавляет +0.5.
