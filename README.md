# Сайт-портфолио

Минималистичный двуязычный (RU / EN) сайт-портфолио на чистом HTML и CSS — без сборки и зависимостей.

## Структура

- `index.html` — русская версия
- `en/index.html` — английская версия
- `assets/style.css` — общие стили (светлая и тёмная тема)

## Как посмотреть

Откройте `index.html` в браузере.

## Что заменить на своё

Имя, тексты, проекты, email и ссылки в обоих файлах — сейчас там примерный контент.

## Публикация (бесплатно)

GitHub → Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)`.
Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.
