# Голос клиента (MTS / MWS): классификация эмоций по аудио-эмбеддингам

Классы: `angry`, `neutral`, `positive`, `sad`. Метрика: macro-F1.

## Структура

| Файл | Что делает |
|---|---|
| `train.py` | обучает финальную модель (ансамбль 5 MLP по фолдам + множители классов под macro-F1), пишет `weights/model.pt` |
| `predict.py` | загружает веса, без обучения пишет `submission_seed_{SEED}.npz` (`embeddings`, `targets`) |
| `src/common.py` | загрузка данных, нормализация, MLP, фиксация seed, подбор множителей классов |
| `experiments/run_experiments.py` | журнал гипотез: одинаковый 5-fold CV для каждой, результаты в `experiments/results.csv` |
| `experiments/blend.py` | проверка ансамблей из разных моделей по OOF-вероятностям |

## Запуск

```bash
pip install -r requirements.txt
# положить train.npz и public_test.npz в data/
python experiments/run_experiments.py --data-dir data   # (опционально) все гипотезы
python train.py --data-dir data                          # seed выбирается случайно и печатается
python predict.py --test data/public_test.npz            # -> submission_seed_{SEED}.npz
```

Воспроизведение: `python train.py --seed <SEED>`. Seed хранится в весах и в имени файла сабмита.

## Решение

1. **Предобработка.** Стандартизация признаков по статистикам train (опционально L2-нормализация).
2. **Модель.** MLP `2048 → 512 → 256 → 4` (BatchNorm, GELU, Dropout 0.2, 40 эпох, ≈1.18 млн параметров на модель), AdamW + OneCycle,
   label smoothing, веса классов `sqrt(1/частота)` против дисбаланса.
3. **Валидация.** Stratified 5-fold; в каждом фолде лучшая эпоха выбирается по macro-F1.
   На тесте вероятности 5 фолдовых моделей усредняются.
4. **Подгонка под macro-F1 (проверено, не помогло).** Обучение идёт по cross-entropy, а оценка по macro-F1, поэтому
   на OOF-вероятностях координатным спуском подбираются множители классов: прогноз
   `argmax(p · s)`. Эффект оценивается честно: множители подбираются на одних фолдах OOF,
   а оцениваются на других (`cv_f1_tuned` в журнале).

## Проверенные гипотезы

Все гипотезы оценены одинаково: 1-й фолд stratified 5-fold (26 200 примеров), 20 эпох для MLP,
если не указано иное. Шум оценки около ±0.3 п.п.

| Гипотеза | Описание | macro-F1 | с множителями | Параметров |
|---|---|---|---|---|
| `knn50` | Косинусный kNN  k=50 | 0.6081 | 0.611 | 0 |
| `mlp_cw05` | MLP + веса sqrt(1/freq) + label smoothing | 0.8692 | 0.8682 | 1 182 980 |
| `logreg_bal` | Логрег + class_weight=balanced | 0.8083 | 0.8137 | 8 196 |
| `mlp_base` | MLP 512-256 без весов классов | 0.8678 | 0.8674 | 1 182 980 |
| `mlp_cw1` | MLP + веса 1/freq | 0.8662 | 0.867 | 1 182 980 |
| `mlp_l2` | MLP + L2-нормализация эмбеддинга | 0.8691 | 0.8685 | 1 182 980 |
| `mlp_half0` | MLP только на 1-й половине эмбеддинга (1024) | 0.7853 | 0.7857 | 658 692 |
| `mlp_half1` | MLP только на 2-й половине эмбеддинга (1024) | 0.8541 | 0.8561 | 658 692 |
| `mlp_small` | Маленький MLP  1 скрытый слой 256 | 0.8633 | 0.8618 | 526 084 |
| `mlp_wide` | Широкий MLP 1024-512 | 0.8694 | 0.8693 | 2 628 100 |
| `mlp_mixup` | MLP + mixup(0.4) | 0.8667 | 0.867 | 1 182 980 |

| `twotower` | Две башни (по половине эмбеддинга) 256+256 -> 256 | 0.8665 | 0.8673 | 658 692 |
| `mlp_drop01` | MLP + dropout 0.1 | 0.8708 | 0.8721 | 1 182 980 |
| `mlp_drop02` | MLP + dropout 0.2 | 0.8715 | 0.8709 | 1 182 980 |
| `mlp_ep40` | MLP 512-256  40 эпох | 0.8723 | 0.8715 | 1 182 980 |

**Выводы**

- Нелинейность нужна: логрег 0.808 → MLP 0.869. kNN слаб (0.608): у близких по косинусу
  эмбеддингов часто разные эмоции (вероятно, один и тот же говорящий).
- Эмбеддинг = две L2-нормированные половины по 1024. Вторая половина сильнее (0.854 против 0.785),
  но вместе лучше обеих. Отдельные «башни» на половины не помогли (0.867).
- Веса классов, mixup, L2-нормализация почти не влияют; сильный dropout (0.5) вредит,
  dropout 0.1–0.2 и 40 эпох немного помогают. Ширина сети больше 512-256 не окупается.
- Подбор множителей классов на train не даёт прироста — модель уже откалибрована под train.

## Сдвиг частот классов (prior shift)

В train angry/positive по 33.6%, neutral/sad по 16.4%, а по условию в реальных звонках
нейтральных больше. `experiments/prior_shift_sim.py` моделирует тест с другими частотами
на OOF-предсказаниях:

| Частоты в тесте | argmax | EM-поправка |
|---|---|---|
| как в train | 0.876 | 0.875 |
| поровну | 0.876 | 0.878 |
| neutral 40% | 0.860 | 0.863 |
| neutral 60% | 0.829 | 0.851 |

EM (Saerens et al., 2002) оценивает частоты классов на тесте без меток и пересчитывает
вероятности `p · π_test / π_train`. Без сдвига ничего не портит, при сдвиге возвращает
до 2 п.п. Включено в `predict.py` по умолчанию (`--prior-shift none` — отключить).
