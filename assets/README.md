# Картинки для игры: как положить и что нарисовать

Игра умеет подхватывать настоящие картинки. Пока файла нет, этот элемент рисуется кодом (как сейчас). Положил файл в нужную папку с нужным именем, и он встал на место. Менять код не нужно. Можно заменять по одному элементу.

Все картинки лежат в `assets/art/`. Формат: PNG с прозрачностью.

## Главное правило: рисовать в двойном размере

Игра показывает картинки вдвое меньше, чем они нарисованы (масштаб 0.5). Тогда всё остаётся чётким при растяжении окна. Например, фон уровня 1920×1080 занимает экран 960×540. Орк ростом 64 пикселя в игре должен быть нарисован ростом 128 пикселей.

Если нужен другой масштаб, положи рядом с анимацией файл `meta.json`:

```json
{"fps": 10, "scale": 0.5, "offset": [0, 0]}
```

`fps` скорость анимации (кадров в секунду; можно по анимациям: `{"walk": 10, "attack": 14}`), `scale` масштаб, `offset` сдвиг картинки в пикселях игры (x, y). Все поля необязательные.

Для **пиксель-арта** положи в `assets/art/` файл `style.json` с содержимым `{"pixel_art": true}`: тогда спрайты рисуются без сглаживания и остаются чёткими.

## Как добавить готовый набор

1. Распакуй набор в папку `raw_art` в корне проекта (например `raw_art/tiny_rpg`). Эта папка не попадает в репозиторий.
2. В `tools/import_art.gd` добавь строки: какой персонаж рисуется какой картинкой, масштаб и оттенок.
3. Запусти `godot --headless --path . --script tools/import_art.gd`. Кадры нарежутся, обрежутся по контуру (ноги внизу по центру) и попадут в `assets/art`.
4. Фон уровня собирается отдельно: `godot --headless --path . --script tools/make_level_bg.gd`.
5. Запиши набор и его лицензию в `assets/CREDITS.md`.

## Где что лежит

```
assets/art/
  title/background.png, logo.png          заставка (1920×1080) и логотип (любой размер, вдвое больше, чем в игре)
  campaign/map.png                        карта кампании (1920×1080)
  levels/orcs/background.png              фон уровня (1920×1080)
  towers/archer_1.png ... mortar_3.png    башни по видам и уровням
  towers/archer_1_shoot/shoot_00.png ...  анимация выстрела (необязательно)
  enemies/<тип>/walk_00.png ...           враги
  heroes/<id>/idle_00.png ... portrait.png герои
  soldiers/knight/idle_00.png ...         рыцари казармы и призванные бойцы
  projectiles/arrow.png ...               стрелы, шары, снаряды
  icons/heart.png ...                     значки интерфейса
  _templates/                             шаблоны-подсказки (не трогать)
```

### Анимации (враги, герои, бойцы)

Кадры это отдельные файлы `<анимация>_<номер>.png`: `walk_00.png`, `walk_01.png`, `walk_02.png` и так далее. Номера идут по порядку. Анимации:

- `walk` ходьба, повторяется по кругу (обязательна для врагов);
- `idle` стоит на месте, повторяется (для героев и бойцов);
- `attack` удар, играет один раз (когда дерётся);
- `die` гибель, играет один раз (пока не используется, можно нарисовать заранее).

Всё рисуется **лицом вправо**, игра сама разворачивает. **Ноги внизу по центру картинки**: эта точка ставится на землю. Все кадры одной анимации одного размера.

Если нарисован только `walk`, остальное игра возьмёт из него.

### Типы врагов (папки `enemies/<тип>`)

`grunt` орк-воин, `raider` наездник на волке, `shield` щитоносец, `berserk` берсерк, `shaman` шаман, `warlock` колдун, `gryph` орк на грифе (летает), `archer` лучник, `brute` громила, `banner` знаменосец, `troll` тролль, `chief` вождь (босс).

### Герои (папки `heroes/<id>`)

`edrik`, `grum`, `kara`, `tarn`, `xol`, `ishta`, `ashgar`, `morven`, `zefira`. Кроме анимаций нужен `portrait.png`: лицо или по пояс для круглой кнопки (рисовать 256×256, в игре 44×44).

Драконы (`ashgar`, `morven`, `zefira`) летают. Рисуй их «в воздухе», тень игра добавит сама.

### Башни

Файлы `towers/<вид>_<уровень>.png`: виды `archer`, `barracks`, `mage`, `mortar`, уровни 1, 2, 3. Всего 12 картинок. **Низ башни по центру картинки** стоит на каменной площадке. Башня вместе с основанием примерно 100–140 пикселей шириной и до 240 высотой (в двойном размере). Вид должен меняться с уровнем (богаче, выше, с золотой отделкой).

### Значки (`icons/<id>.png`, квадрат 128×128)

`heart` жизни, `coin` золото, `flag` волна, `star_full` и `star_empty` звёзды, `pause`, `play`, `speed`, `back`, `up` (улучшить), `lock`, `gear`, `close`, `trash`; башни `tower_archer`, `tower_barracks`, `tower_mage`, `tower_mortar`; способности героев `ab_<id героя>`; заклинания `sp_<id>` (`sp_knights`, `sp_meteors`, `sp_reinforce`, `sp_quake`, `sp_frost`, `sp_wrath`, `sp_wave`, `sp_fireball`).

### Снаряды (`projectiles/<вид>.png`)

`arrow`, `arrow_big` (мощный выстрел Тарна), `orb` (магический шар), `shell` (снаряд мортиры), `meteor`. Рисуется **острием вправо** (игра сама поворачивает).

## Шаблоны

В `assets/art/_templates/` лежат картинки-подсказки 1920×1080: `level_orcs_guides.png` (дорога, 11 площадок с номерами, ворота и лагерь), `campaign_map_guides.png` (10 локаций кампании по номерам), `title_guides.png` (где логотип и кнопки). Красные зоны это места, которые закроет интерфейс: там не нужно рисовать ничего важного. Подкладывай шаблон под свой рисунок, чтобы дорога и площадки совпали. Или покажи его художнику или нейросети как основу композиции.

Дорога и площадки в игре заданы числами (`scripts/defs.gd`: `PATH` и `PADS`), а не картинкой. Поэтому фон должен точно повторять шаблон. Если нужна другая дорога, скажи, и числа поменяем.

## Как проверить

```
godot --headless --path . res://tests/art_check.tscn
```

Покажет, что найдено, чего ещё не хватает, и сохранит «контактный лист» всех найденных картинок (путь будет напечатан). Запусти игру и посмотри глазами: якоря (ноги внизу по центру), размеры и сдвиги.

## Задание художнику

Стиль: мультяшная, яркая, ручная рисовка с крупными выразительными персонажами, серьёзная история без пародии (выдуманная земля, классическое фэнтези). Все персонажи и рисунки свои, чужие игры не копируем.

Мир: люди защищаются от Древней Тьмы, пробудившегося некроманта, который подчиняет разные расы. Первая локация: орки в лесу. Дальше гоблины, шаманы, огры, йети, гномы, минотавры, драконы, осьминоги и кладбище некроманта.

Что нужно для первого уровня (орки), всё в двойном размере:

| Что | Сколько |
|---|---|
| Враги (12 типов) | каждому `walk` 6–8 кадров, `attack` 4–6 кадров, `die` 4–6 кадров |
| Герои (9) | `idle` 4–6, `walk` 6–8, `attack` 4–6 кадров и `portrait` |
| Рыцари казармы | `idle`, `walk`, `attack` |
| Башни людей | 4 вида по 3 уровня (12 картинок), по желанию анимация выстрела |
| Фон уровня | 1 картинка 1920×1080 по шаблону |
| Карта кампании | 1 картинка 1920×1080 по шаблону |
| Заставка и логотип | фон 1920×1080 и логотип |
| Значки | около 45 штук, 128×128 |
| Снаряды | 5 штук |

## Откуда взять картинки

- **Художник** (фрилансер): лучший результат, единый стиль. Дай ему этот файл, шаблоны и `CLAUDE.md`.
- **Готовые наборы** (itch.io, CraftPix, Kenney): быстро и недорого, но стили разных наборов плохо сочетаются. Обязательно проверь лицензию на коммерческое использование.
- **Нейросети** хорошо подходят для статики (фон, карта, заставка, портреты). Анимированных персонажей в одном стиле они делают плохо. Проверь правила сервиса по правам на результат.
- Картинки из Kingdom Rush и других игр брать нельзя: они защищены авторскими правами.
