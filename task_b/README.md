# Задача B «Подбери страховку» (Сбер): бинарная классификация `accepted`, метрика F1

Финал: seed **654255**, публичный LB **96.70**.

## Запуск
```bash
pip install -r requirements.txt
python task_b/train.py --seed 654255                 # обучение (данные: task_b/data/train.csv) -> task_b/weights/
python task_b/predict.py --test <test>.csv --out-dir out   # без обучения -> out/submission_seed_654255.csv
```
Seed хранится в `task_b/weights/meta.json` и в имени файла сабмита.

## Модель
Смесь 50/50 двух ансамблей по 5 фолдам (StratifiedKFold), порог 0.5 (подобран на OOF):
1. **GAM**: кубический сплайн (3 узла по квантилям) на каждый числовой признак, one-hot категорий,
   индикаторы пропусков и 4 попарных произведения стандартизованных признаков; сверху логистическая регрессия.
   Аддитивна в логит-шкале и интерпретируема: ≈167 коэффициентов на модель (834 на 5 фолдов).
2. **CatBoost** depth=4, lr 0.03, early stopping по фолду (600–1100 деревьев).

Пары взаимодействий (`common.PAIRS`) отобраны жадно по CV (`experiments/interactions.py`):
цена×возраст смартфона, доход×возраст смартфона, отклик на прошлую кампанию×прошлая страховка,
цена смартфона×доля онлайн-платежей.

## Проверенные гипотезы
Все варианты в `results.csv` (5-fold CV, F1 при подобранном пороге), запуск `python task_b/run_experiments.py`.

| Модель | CV F1 | Публичный LB |
|---|---|---|
| логрег (one-hot, медианы) | 0.939 | — |
| LightGBM | 0.948 | — |
| CatBoost | 0.949 | 95.45 |
| CatBoost depth=4 | 0.951 | — |
| GAM 12 / 5 / 3 узла | 0.939 / 0.958 / 0.959 | — |
| GAM 3 узла + CatBoost d4 (50/50) | 0.961 | 96.18 |
| **+ 4 пары взаимодействий в GAM (финал)** | **0.961** (GAM 0.9589 → 0.9613) | **96.70** |

Выводы: данные почти аддитивны в логит-шкале, поэтому гладкий GAM с малым числом узлов лучше бустинга;
больше узлов переобучается. Сгенерированные признаки (отношения к доходу и т. п.) не помогли.
Бустинг добавляет немного нелинейности, смесь лучше каждой модели.
