# Задача D «Клиент под защитой» (Сбер): регрессия `protection_score` (0–100), метрика RMSE

Финал: seed **352773**, публичный LB **77.25** (RMSE на тесте ≈ 1.59).

## Запуск
```bash
pip install -r requirements.txt
python task_d/train.py --seed 352773                 # обучение (task_d/data/hard_train.csv) -> task_d/weights/
python task_d/predict.py --test <test>.csv --out-dir out   # без обучения -> out/submission_seed_352773.csv
```

## Главная особенность данных
Метки train сильно зашумлены: CV RMSE ≈ 10.4, а на тесте ≈ 1.6, то есть тестовые метки почти чистые.
Шум латентный, в логит-шкале: `y = 100·sigmoid(z + ε)`, std ε ≈ 0.6 на всех уровнях, асимметрия ≈ 0.
Поэтому CV на шумных метках плохо ранжирует модели, и решения проверялись на публичном LB (по 1–3 пробы на гипотезу).

## Модель
Три уровня сложности, на каждом CatBoost ×5 seed и LightGBM ×5 seed (с признаками «покрытия рисков»:
есть актив и есть/нет страховки на него, кибергигиена, доля активных полисов и т. п.), всё усредняется:

| уровень | CatBoost depth | LightGBM leaves / min_child / λ |
|---|---|---|
| base | 6 | 8 / 40 / 5 |
| mid | 7 | 16 / 30 / 1 |
| sharp | 8 | 31 / 20 / 1 |

Число деревьев выбрано по early stopping на 5-fold CV ×1.1. Смесь моделей разной сложности снижает
разброс, и это главный резерв при таком шуме.

## Проверенные гипотезы (публичный LB)
| Гипотеза | LB |
|---|---|
| константа (среднее) | 0 (проверка формулы баллов: 100·(1 − RMSE/7)) |
| LightGBM | 71.64 |
| ridge на logit(y) (лучший CV 10.25!) | 54.39 |
| LightGBM на logit-цели | 62.16 |
| LGBM leaves 8 + признаки ×5 / CatBoost ×5 / их среднее | 72.49 / 72.55 / 75.62 |
| CatBoost ×5 + LightGBM ×5 | 76.27 |
| + RandomForest / + XGBoost / взвешенный МНК 1/σ² | 70.31 / 76.22 / 71.14 |
| «сглаженные» модели / топ-30 признаков | 74.46 / 74.21 |
| абляция групп: без survey / regional / claims / aggregates | 70.13 / 74.93 / 76.03 / 38.08 |
| sharp (d8/31) / sharper (d10/63) | 76.48 / 73.84 |
| base + sharp / **base + mid + sharp (финал)** | 77.09 / **77.25** |
| + MLP 20% | 72.63 |
| медиана латентной модели (QuantReg-калибровка, медианные модели) | 72.65 / 70.30 |

| пробы вдоль направления «бленд − ridge» (±0.5) | 71.67 / 69.30 (бленд в оптимуме) |

Выводы: на тесте выигрывает только MSE-регрессия по y деревьями и ансамбли разной сложности. Модели
с логит-потерей и линейные модели лучше на шумном CV, но хуже на тесте (CV-MSE − тест-MSE у моделей
разное). Скрипты экспериментов лежат в `experiments/`, подробный журнал — в `NOTES.md` в корне.
